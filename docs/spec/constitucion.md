## Convenciones

- Ramas: `cmp-02-bloqueo-segunda-toma`
- Commits: `tipo: CMP-XX descripción` — tipos: `spec`, `feat`, `fix`, `test`, `docs`
- Títulos de issue: empiezan con el código del comportamiento
- El `closes #n` va en el pull request que integra, no en cada commit
- Pull request por tarea, con al menos un revisor distinto del autor

## Definición de Listo

Base obligatoria — se adopta completa:

- [ ] La historia está escrita con actor, acción y beneficio
- [ ] Tiene al menos un criterio de aceptación verificable
- [ ] Está trazada al requerimiento del Módulo 1 del que proviene
- [ ] Cabe en una sesión de trabajo de una persona
- [ ] No depende de otra historia que no esté terminada
- [ ] El equipo entiende qué hay que hacer sin volver a preguntar

## Definición de Terminado

Base obligatoria — se adopta completa:

- [ ] El criterio de aceptación se cumple, y lo verificó alguien distinto de quien construyó

- [ ] La tarea está cerrada en el tablero
- [ ] No rompe nada de lo que ya funcionaba
- [ ] Si se usó IA, alguien del equipo revisó lo generado y puede explicarlo
